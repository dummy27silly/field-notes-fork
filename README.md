# Fieldnotes landing page

A basic, responsive landing page built with modular HTML, CSS, and JavaScript.

## Structure

- `index.html` — page content and semantic structure
- `css/styles.css` — layout, typography, colors, and responsive styles
- `js/main.js` — smooth scrolling, article expansion, and reveal effects

Open `index.html` in a browser or publish this folder with GitHub Pages.
